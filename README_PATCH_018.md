# Patch 018 — Signal Email Employee

Patch 018 composes the earned layers into the first complete vertical employee. It introduces no new authority mechanism.

One tick performs:

`Gmail poll → durable inbound event → Signal task → leased worker → deterministic/model triage → reply artifact + waiting ActionRequest → exact standing-delegation assessment → one-use delegated warrant → lease recheck → existing runtime Gmail dispatch`.

The employee requires an explicit `delegation_id` and a caller-provided source of current continuation facts. It cannot create its own standing delegation or broaden its mandate.

Intake degradation does not prevent already-durable Signal tasks from being drained. Human-review/no-reply decisions never enter the authorization/dispatch path. A failed standing assessment creates no warrant and no send. The process loop survives task/provider/adapter failures instead of terminating the employee.
